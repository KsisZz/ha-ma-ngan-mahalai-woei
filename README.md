# หามางานมหาลัยเว้ย — ตัวอัปเดตออนไลน์แบบไม่ใช้ API เสียเงิน

ตรวจประกาศจากเว็บไซต์มหาวิทยาลัยในประเทศไทยทุกชั่วโมงผ่าน GitHub Actions บน standard Ubuntu runner ใน repository สาธารณะ ไม่ต้องเปิดคอม ไม่ต้องใช้ Ollama ไม่ต้องใส่ API key และไม่ต้องใส่ข้อมูลบัตรเครดิต

โปรเจกต์นี้เผยแพร่เฉพาะโค้ดและข้อมูลประกาศงานสาธารณะ ไฟล์ส่วนตัว กุญแจ และรหัสผ่านไม่อยู่ในโปรเจกต์

- Workflow ทำงานเฉพาะ repository ที่เป็น public และใช้ ubuntu-latest เท่านั้น
- ไม่มี paid runner, AI API, cache หรือ artifact ที่คิดค่าจัดเก็บ
- เขียนผลลง snapshot.json เพื่อให้เว็บอ่านข้อมูลล่าสุดได้
- รอบเวลาตามกำหนดอาจล่าช้าตามคิวของ GitHub
- บางมหาวิทยาลัยมีหน้า JavaScript หรือ PDF ที่อ่านอัตโนมัติไม่ได้ จึงมีลิงก์ต้นทางไว้ให้เปิดดู
- อ่านเฉพาะงานประจำ/พนักงานมหาวิทยาลัย/ข้าราชการที่มีวันปิดรับชัดเจน ไม่แต่งตำแหน่งหรือวันปิดรับ

เงื่อนไขผู้ให้บริการอาจเปลี่ยนในอนาคต ไม่มีการรับประกันว่าบริการภายนอกจะฟรีตลอดไป ระบบนี้ไม่สมัครแผนเสียเงินหรือเปิดการจ่ายส่วนเกินให้อัตโนมัติ

เอกสาร: https://docs.github.com/en/actions/concepts/billing-and-usage
